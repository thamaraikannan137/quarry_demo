Open `index.html` in a browser (double-click or drag into Chrome/Safari).

2. Use top **Year (FY)** switcher — Indian FY Apr–Mar (2024-25, 2025-26, 2026-27)

- Dashboard, All Transactions, Sale, Purchase & Expense, Payroll (attendance tap cycle, salary, labour)
- Block marking (L×W×H → CBM), Buyers, Royalty, Machinery, P&L
- Data saved in browser `localStorage` (↺ resets demo)
